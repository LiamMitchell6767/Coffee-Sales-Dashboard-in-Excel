# Coffee Sales Excel Dashboard Project

## Project Overview
This Excel project involves creating a comprehensive Coffee Sales Dashboard using data cleaning, PivotTables, and interactive visualizations. The dashboard enables users to explore coffee sales performance through dynamic filters, providing insights into sales trends, customer purchasing behavior, country performance, and product preferences. ## Objectives
- Analyze coffee sales performance and identify key trends.
- Create an interactive dashboard for exploring sales data.
- Provide insights into customer behavior, product performance, and geographic sales distribution.
## Data Analysis Process

### 1. Data Cleaning
Identified and removed duplicate records, standardized categorical data, and ensured consistency across datasets.

### 2. Data Preparation
Combined relevant information from multiple source tables into a consolidated dataset while preserving the original raw data tables for data integrity and reference.

### 3. Data Analysis
Utilized PivotTables to summarize coffee sales data and generate key metrics for identifying trends and business insights.

### 4. Data Visualization
- Build visualizations using appropriate charts to highlight key insights, including:
  - Sales trends over time
  - Sales performance by country
  - Customer purchasing behavior
  - Product and roast type performance

### 5. Dashboard Creation
Developed an interactive dashboard by combining visualizations with filters, slicers, and timelines to allow users to explore coffee sales performance dynamically.

## Excel Functions Used
- **XLOOKUP** – Retrieved and combined information from different tables.
- **INDEX & MATCH** – Used for advanced lookup operations and data merging.
- **IF Functions** – Created conditional categories and classifications.
- **Date Formatting** – Standardized date fields for time-based analysis.
- **Number Formatting** – Improved readability and consistency of numerical data.

## Excel Features Used
- **PivotTables** – Summarized and analyzed sales data.
- **PivotCharts** – Created visual representations of key metrics.
- **Slicers** – Added interactive filtering capabilities.
- **Timeline** – Enabled date-based exploration of sales trends.
- **Dashboard Design** – Combined visualizations into an interactive reporting tool.


# 咖啡銷售 Excel 儀表板專案

## 專案概述
此 Excel 專案旨在建立一個完整的咖啡銷售儀表板，運用資料清理、PivotTables 以及互動式視覺化。此儀表板讓使用者能夠透過動態篩選功能探索咖啡銷售表現，並提供關於銷售趨勢、客戶購買行為、國家銷售表現以及產品偏好的洞察。

![咖啡銷售儀表板](https://github.com/LiamMitchell6767/Coffee-Sales-Dashboard-in-Excel/blob/a8813c7cf2af837b628031397d8be3686cb9e7d8/Screenshot%202026-08-04%20173609.png)
[查看儀表板](https://github.com/LiamMitchell6767/Coffee-Sales-Dashboard-in-Excel/blob/66abd82db762686b9ab6649978177c943424e662/Coffee%20Sales%20Dashboard.xlsx)


## 專案目標
- 分析咖啡銷售表現並找出主要趨勢。
- 建立互動式儀表板以探索銷售資料。
- 提供關於客戶行為、產品表現以及地理銷售分布的洞察。

## 資料分析流程

### 1. 資料清理
識別並移除重複資料、標準化類別型資料，並確保資料集的一致性。

### 2. 資料準備
整合多個來源資料表中的相關資訊，建立統一的資料集，同時保留原始資料表以維持資料完整性並方便後續參考。

### 3. 資料分析
利用 PivotTables 彙整及分析咖啡銷售資料，並建立關鍵指標以找出趨勢與商業洞察。

### 4. 資料視覺化
使用適當的圖表建立視覺化，以呈現重要洞察，包括：
- 隨時間變化的銷售趨勢
- 各國銷售表現
- 客戶購買行為
- 產品與烘焙程度表現

### 5. 儀表板建立
透過整合視覺化圖表、篩選器以及時間軸，建立互動式儀表板，使使用者能夠動態探索咖啡銷售表現。

## 使用的 Excel 函數
- **XLOOKUP** – 從不同資料表中查找並整合資訊。
- **INDEX & MATCH** – 用於進階查找操作與資料合併。
- **IF 函數** – 建立條件分類與資料分類。
- **日期格式設定** – 標準化日期欄位以進行時間分析。
- **數字格式設定** – 提升數值資料的可讀性與一致性。

## 使用的 Excel 功能
- **樞紐分析表** – 彙整並分析銷售資料。
- **樞紐分析圖** – 建立主要指標的視覺化呈現。
- **切片器** – 加入互動式資料篩選功能。
- **時間軸** – 提供依日期探索銷售趨勢的功能。
- **儀表板設計** – 將多個視覺化圖表整合成互動式分析工具。
